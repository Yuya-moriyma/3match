# 画面設計書

## 概要
本ドキュメントは、3マッチパズルバトルゲームの画面設計について定義する。

---

## 画面一覧

| 画面名 | 説明 |
|--------|------|
| タイトル画面 | ゲーム起動時の最初の画面 |
| メニュー画面 | 各機能へのハブとなる画面 |
| バトル準備画面 | バトル前の準備・確認を行う画面 |
| ストーリー画面 | ストーリー・会話シーンを表示する画面 |
| バトル画面 | パズルバトルを行うメイン画面 |
| リザルト画面 | バトル終了後の結果表示画面 |
| 設定画面 | ゲーム設定を変更する画面 |

---

## 画面遷移図

```
[タイトル画面]
      ↓
[メニュー画面] ←─────────────────────────────────────────────┐
      ├→ [バトル準備画面] → [ストーリー画面] → [バトル画面] → [リザルト画面] ─┘
      │         ↓                   ↑
      │    (デバッグボタン)─────────┘
      │    ※将来: 特定条件で自動遷移
      │
      ├→ [設定画面] ─────────────────────────────────────────┘
      └→ タイトルへ戻る
```

## 各画面詳細

### 1. タイトル画面

#### 目的
- ゲームの第一印象を与える
- ゲーム開始への導線を提供する

#### 表示要素
| 要素 | 説明 |
|------|------|
| ゲームロゴ | 画面中央上部に配置 |
| 背景イメージ | ゲームの世界観を表現 |
| 「TAP TO START」 | 画面タップでメニューへ遷移 |
| バージョン情報 | 画面右下に小さく表示 |

#### 操作
- 画面タップ → メニュー画面へ遷移

#### レイアウト案
```
┌────────────────────────────────────┐
│                                    │
│          [ゲームロゴ]              │
│                                    │
│                                    │
│         TAP TO START               │
│                                    │
│                                    │
│                         ver 0.0.1  │
└────────────────────────────────────┘
```

### 2. メニュー画面

#### 目的
- 各機能へのアクセスを提供する
- プレイヤーの現在状態を表示する

#### 表示要素
| 要素 | 説明 |
|------|------|
| プレイヤー情報 | 名前、レベルなど |
| ストーリーボタン | ストーリー選択画面へ |
| 設定ボタン | 設定画面へ |
| 戻るボタン | タイトル画面へ |

#### 操作
- ストーリーボタン → バトル準備画面へ遷移
- 設定ボタン → 設定画面へ遷移
- 戻るボタン → タイトル画面へ遷移

```
│                                    │

│                                    │
│────────────────────────────────────│
│                                    │
│       ┌──────────────────┐         │
│       │   ストーリー     │         │
│       └──────────────────┘         │
│                                    │
│                                    │
└────────────────────────────────────┘
```

### 3. バトル準備画面

#### 目的
- バトル前の準備・確認を行う
- ステージ情報や敵情報を事前に把握させる
- ストーリー画面への遷移条件を管理する

#### 表示要素
| 要素 | 説明 |
|------|------|
| ステージ情報 | 章・ステージ名、難易度など |
| 敵情報 | 出現する敵の概要 |
| 出撃ボタン | バトル画面へ直接遷移 |
| 戻るボタン | メニュー画面へ戻る |
| [DEV] ストーリーボタン | デバッグ用：ストーリー画面へ遷移 |

#### 操作
- 出撃ボタン → バトル画面へ遷移
- 戻るボタン → メニュー画面へ遷移
- [DEV] ストーリーボタン → ストーリー画面へ遷移（デバッグ用）

#### 将来的な仕様
- 特定条件（初回プレイ、ストーリー進行フラグなど）を満たすと自動的にストーリー画面へ遷移
- デバッグボタンは本番環境では非表示

```
│                                    │

│  ┌────────────────────────────┐    │

│  │  ・白狼 Lv.5               │    │
│  │  ・HP: ???                 │    │
│  └────────────────────────────┘    │
│                                    │
│────────────────────────────────────│
│                                    │
│       ┌──────────────────┐         │
│       │      出撃        │         │
│       └──────────────────┘         │
│                                    │
│  [DEV: ストーリー再生]             │
│                                    │
└────────────────────────────────────┘
```

### 4. ストーリー画面

#### 目的
- ストーリー・会話シーンを演出する
- プレイヤーを物語に没入させる

#### 表示要素
| 要素 | 説明 |
|------|------|
| 背景画像 | シーンに応じた背景 |
| キャラクター立ち絵 | 話者のキャラクター表示 |
| テキストウィンドウ | セリフ・ナレーション表示 |
| キャラクター名 | 話者の名前 |
| スキップボタン | ストーリーをスキップ |
| オートボタン | 自動進行ON/OFF |

#### 操作
- 画面タップ → 次のテキストへ進む
- スキップボタン → バトル画面へ遷移（確認ダイアログ表示）
- オートボタン → 自動進行の切り替え

```
│    │    │              │    │     │
│    └────┘              └────┘     │
│                                    │
│┌──────────────────────────────────┐│
││ キャラ名                         ││
││──────────────────────────────────││

││ テキストテキストテキスト...  [▼] ││
│└──────────────────────────────────┘│
└────────────────────────────────────┘
```

### 5. バトル画面

#### 目的
- パズルバトルのメインプレイを提供する
- プレイヤーと敵の状態を可視化する

#### 表示要素
| 要素 | 説明 |
|------|------|
| 敵キャラクター | 敵の見た目表示 |
| 敵HPバー | 敵の残りHP |
| 敵行動カウンター | 敵攻撃までの残り操作数 |
| 自分HPバー | プレイヤーの残りHP |
| パズル盤面 | 6×6のタイル盤面 |
| ボーナスパネルストック | 生成されたボーナスパネル |
| 一時停止ボタン | ポーズメニューを開く |

#### 操作
- タイルスワイプ → タイルを入れ替え
- ボーナスパネルタップ → ボーナス効果発動
- 一時停止ボタン → ポーズメニュー表示

#### ポーズメニュー

## 共通UIコンポーネント

### ボタン
- Bootstrapのボタンコンポーネントをベースに使用
- ゲームの世界観に合わせたカスタムスタイルを適用

### ダイアログ
- 確認が必要な操作時に表示
- 「はい」「いいえ」の選択肢を提供

### ローディング
- 画面遷移時に表示
- シンプルなスピナーまたはプログレスバー

---

## デザイン方針

1. **Bootstrapの活用**
   - レイアウト、グリッドシステムはBootstrapを使用
   - レスポンシブ対応を容易にする

2. **CSSによる世界観表現**
   - ファンタジー世界観に合わせた配色
   - 童話をモチーフとしたビジュアル装飾

3. **ユーザビリティ**
   - 直感的な操作を重視
   - タップ領域は十分な大きさを確保
   - フィードバック（アニメーション、効果音）を適切に提供
